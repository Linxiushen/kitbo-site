01

产品定义与卖点

Microduck 证明了"15 颗 XL330 + RK3566 就能跑 50 Hz 神经网络策略"，也证明了双足难训：头占 1/4 质量、重心高，官方用了几十轮 reward 迭代。MicroCat 把同一套电控搬到四足上——静态稳定、走路策略在 CPU 上几十分钟收敛——把预算花在"猫的行为"上：伸懒腰、踩奶、蹭头、蹲伏扑击、甩尾、竖耳。每一个都是一个 RL 任务，也是一个社交媒体素材。

  1. 会撒娇的开源机器猫16 关节 + 2 只可动耳朵 + 圆形显示屏眼睛。动作是训练出来的策略，不是预录动画。
  2. 在仿真里训练，在现实里陪伴MuJoCo 模型与 CAD 同源；train → export.onnx → robotctl policy add，一条命令换一个"脑子"。
  3. 它能看见你IMX219 摄像头 + 8×8 ToF + RK3566 NPU：跟着你走、追激光点、认出主人、躲开桌沿。
  4. 摸它会有反应头顶与背部电容触摸电极：摸头 → 眯眼 + 呼噜 + 尾巴慢摆；拍背 → 弓背。
  5. 1 小时续航，可换电池与 Microduck 同款 Sony NP-F550，装在腹部，重心极低。
  6. Rust 运行时，不变砖继承七守护进程架构 + 新增 facd / touchd / moodd；签名更新、健康门控、自动回滚。
  7. 开源到底软件 Apache-2.0，CAD（STEP）与 MJCF 也开源——这是 Microduck 没做的事。

AI 能力：它能听、能看、能说、能学

Microduck 的源码里有音频抚摸检测、每只鸭子独一无二的合成嗓音、NPU 检测规划和"服务器端 LLM 控制机器人"的架构，但没有语音对话。MicroCat 把这一层补上，并分两档：本地小模型（不联网也能听懂、回应）与云/边端大模型（联网后看图、聊天、多步任务）。

听 · 说

唤醒词 → 本地语音识别 → 小模型 → 猫嗓音

openWakeWord + sherpa-onnx 流式识别 + Qwen2.5-0.5B/1.5B（llama.cpp，板载 CPU）做意图解析与短回复，Piper TTS 与每只猫唯一 seed 的合成喵声/呼噜。本地档说一句"过来"到猫起步约 1.5–2.5 s。

看

NPU 检测 + 8×8 深度

RK3566 NPU 跑 YOLOv8n（320 输入，15–30 Hz）识别人/手/猫/激光点：跟着你走、追激光、认出主人；ToF 深度做桌沿与障碍检测；MPR121 触摸 + 音频"挠头"分类双通道感知抚摸。

连大模型

手机 / 电脑 / 云上的 LLM 与 VLM

沿用 Microduck 架构里的"服务器端 agent"模式：WebSocket JSON-RPC + 按需取摄像头帧；Claude / GPT / 本地 Ollama 都能当它的大脑，同一套工具调用（move / head / tail / posture / trick / face / say）；机器人侧安全层否决危险意图。

04

软件架构

沿用 Microduck 的守护进程分工（能碰电机的只有 robotd），但整套栈已用 Python 完整实现并可烧录：software/microcat 七个守护进程 + Dynamixel 协议层 + 安全层 + ONNX 策略运行时，software/deploy 提供 systemd 单元、udev、设备树 overlay、安装与镜像脚本。同一份 robotd 代码只换总线后端即可在 MuJoCo 里跑（上方“摔倒自恢复”演示即由它录制）。

05

仿真与强化学习

Mac 上没有 CUDA，所以不用 mjlab（MuJoCo Warp），而是原生 MuJoCo 多线程 + 自写 PPO（rsl_rl 同配方）。执行器用 microduck_rl 里 BAM 标定过的 XL330 等效 PD（kp 0.55，±0.96 N·m），加 kp / 摩擦 / 质量 / 延迟随机化与推撞。M5 上吞吐约 22k 步/秒。

训练前验证（AGENTS.md：先验证物理假设）结果
站立稳定性：STAND 指令保持 3 s，8 次随机扰动倾角均值 1.7°、最大 3.4°；四脚触地，前 1.9 N / 后 2.75 N
舵机柔性下沉髋 pitch −7°、膝 −10~−13° → 躯干高度 118 → 106 mm，环境启动时实测作为高度目标

动作演示

前两支是强化学习技能：行走策略 v2 的全向指令测试（前进 / 横移 / 转向 / 斜行 / 后退，一个 ONNX 完成）与摔倒自恢复（被撞倒后自己爬起来再走）；其余九个基础动作与一支舞是把关节目标序列（50 Hz）喂给仿真里的 16 颗舵机模型，猫要靠自己保持平衡（全部动作未摔倒）。同一份动作可直接在真机上回放。
